🌐 Live Demo

[View Live Portfolio](https://mohima-portfolio-git-main-mohima202.vercel.app/)

✨ Features
* Modern 5D-inspired futuristic UI
* Glassmorphism design
* Interactive mouse-following 3D effects
* Fully responsive design
* Separate pages for About, Skills, Projects, Education, and Contact
* Contact form with EmailJS integration
* Smooth navigation with React Router
* Project showcase with GitHub and live demo links

🛠️ Technologies Used
* React.js
* JavaScript
* Tailwind CSS
* Vite
* React Router
* EmailJS
